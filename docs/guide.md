# 使い方ガイド

縦書き小説エディタ tauri-tate-editor の操作方法をまとめる。
設計の理由や実測の記録は [README](../README.md) を参照。
アプリ内では、画面右下の「ヘルプ」からも主な操作を確認できる。

## 画面の見かた

- **上段（ツールバー）** … ファイル操作、記法、表示モード、判型・書体・
  配色・マス目、品詞マーカーの設定
- **中央（用紙）** … 本文。縦書きで、右端の行から始まる
- **下段（ステータスバー）** … 開いているファイル名、文字数・枚数・
  ページ数、マーカー数、状態表示、「ヘルプ」

## ファイル

| 操作 | キー |
|---|---|
| 開く | `Ctrl+O` |
| 保存 | `Ctrl+S` |
| 名前を付けて保存 | `Ctrl+Shift+S` |

- 読み込みの文字コードは自動判定（UTF-8 / Shift_JIS / EUC-JP）。
  改行コードと BOM は保存時に元どおりに戻る
- 編集中の原稿は 1 分ごとに、開いているファイルの隣へ
  `～.autosave` として自動保存される。保存されないまま終了した場合、
  次にそのファイルを開いたときに復元するか尋ねる
- 上書き保存のたびに、旧版が世代バックアップとして退避される

## 書きはじめる

- 段落は Enter で分ける。字下げは行頭に全角空白を打つ（1 マスとして残る）
- 行頭に `＃` を置くと見出しになる。`＃＃`、`＃＃＃` と増やすと下の階層に
  なる（全角を推奨。半角 `#` も認識するが、その行だけ升からずれる）
- `Ctrl+G` で目次を開き、見出しへ飛べる。章ごとの文字数も出る
- 「正規化」ボタンは、マス目からずれる文字（ダーシ `—` と半角英数）を
  全角へ寄せる。対象があるときだけ押せる

## 判型と見た目

- **判型** … 原稿用紙（20×20）・文庫（42×16）・新書・四六判などの
  プリセット。字数・行数は個別にも変えられる
- **文字サイズと行送りは自動**。1 行がちょうど画面の高さに収まる大きさに
  決まり、行間にはルビと傍点のぶんの余白が確保される
- **書体** … 「標準」の 5 書体に加えて、インストール済みの日本語フォント
  から選べる。仮名が詰まるプロポーショナル書体（BIZ UDP 系など）を
  選ぶと「升目からずれます」と警告が出る
- **マス目** … 升目 / 行罫のみ / ページ区切りのみ / なし
- **配色** … 白・生成り・夜。夜はマーカーの色も見やすい側へ切り替わる
- これらの設定は自動で保存され、次に開いたときも同じ見た目で始まる

## 記法とプレビュー

投稿先ごとのルビ・傍点の書き方（記法）を選べる。記法を切り替えると、
本文中のルビと傍点も書き換わる。

| 記法 | ルビ | 傍点 |
|---|---|---|
| 小説家になろう | `\|漢字《かんじ》` | 中黒ルビで代用 |
| カクヨム | `\|漢字《かんじ》` | `《《文字》》` |
| 青空文庫 | `｜漢字《かんじ》` | `［＃「文字」に傍点］` |
| pixiv | `[[rb:漢字 > かんじ]]` | 中黒ルビで代用 |

- 傍点の書き方がない記法（なろう・pixiv）へ移しても、傍点は中黒のルビ
  （`|文字《・・》`）で代用されるので消えない。戻せば元の書き方に戻る
- `Ctrl+E` で「記法」と「プレビュー」を切り替える。**どちらでも編集できる**
- プレビューではルビ・傍点が実際の形で表示され、見出し記号（＃）は
  見えなくなる（マスは詰めない）。ルビの親文字や傍点の文字は、その場で
  打ち替えられる

## ルビ — Ctrl+R

1. ルビを振りたい文字を選択して `Ctrl+R`
2. 小窓に読みを入れて Enter（Esc で取消）

- すでにルビのある場所で押すと、いまの読みが入った状態で開く
- **読みを空にして Enter するとルビが外れる**
- プレビューでは、ルビ（読み）をクリックしても小窓が開く
- 何も選ばずに押すと、いまの記法での書き方を状態表示に出す

## 傍点 — Ctrl+B

文字を選択して `Ctrl+B`。すでに付いていれば外れる。
ルビを含む範囲には付けられない。

## 類義語 — Ctrl+Q

キャレットを語の上に置いて `Ctrl+Q`（または「類語」ボタン。
`Ctrl+I` でも可）。候補が三段で出る。

- **言い換え** … 厳密な同義語（Sudachi 同義語辞書）
- **同義** … 同じ概念の語（日本語 WordNet）。多義語は意味ごとに
  グループが分かれる
- **近い意味** … 意味の近い語・上位/下位の語

候補をクリックするとその語に置き換わる（`Ctrl+Z` で戻せる）。
Esc か外側クリックで閉じる。活用した形（「歩い」）の上でも引ける。

## 品詞マーカー

副詞・形容詞・形容動詞・連体詞に自動で印が付く。書きすぎ・使いすぎの
発見に使う。

- 「マーカー」で表示スタイルを選ぶ（蛍光ペン・傍線・文字色など。
  「傍線（右）」が日本語の慣習）
- 「対象品詞」で品詞ごとに入り切りできる。「マーカー表示」で全体を消せる
- 記法表示でもプレビューでも出る。印刷には出ない

## 文体パネル

「文体」ボタンで開く。本文を調べて、推敲の手がかりを指摘する。

| 種類 | 既定 |
|---|---|
| 長い文 | 200 字を超える一文 |
| 文末の重なり | 同じ末尾 2 字の文が 3 つ続く |
| 近くの繰り返し | 同じ語が 60 字以内に再登場 |
| 使いすぎ | 指定した語が千字あたり 4 回以上 |
| 表記ゆれ | 「子供／子ども」のような表記の混在 |

- 指摘をクリックするとその場所へ飛んで強調される。もう一度クリックか
  Esc で解除
- しきい値と「数える語」は「しきい値」から変えられ、設定は保存される
- 表記ゆれは、少ないほうの表記の初出に印が付く（多数派に合わせて
  直すことが多いため）

## 検索・置換

| 操作 | キー |
|---|---|
| 検索 | `Ctrl+F` |
| 置換 | `Ctrl+H` |
| 次へ / 前へ | `F3` / `Shift+F3`（Enter / Shift+Enter でも） |

正規表現と大文字小文字の区別に対応。「すべて置換」は件数を確認してから
実行される。

## 元に戻す・やり直す

`Ctrl+Z` / `Ctrl+Y`（`Ctrl+Shift+Z` でも可）。
ルビ・傍点・類義語の置き換え・削除もすべて戻せる。

## 削除の作法 — まず注記から

ルビ・傍点・見出し記号に Backspace / Delete が触れると、
**一度目は注記だけが外れて文字が残る**。

- ルビ → 読みが外れて親文字が残る
- 傍点 → 点が外れて文字が残る
- 見出し記号（＃）→ 記号が消えて、その行は見出しでなくなる

もう一度消すと、ふつうの文字として消えていく。消しすぎて本文まで
失うことがない。

## 行末の句読点

行末に入りきらない句読点（、。）は、升の外へぶら下がる（ぶら下がり組み）。
書いている場所のすぐ近くでは一時的に解けて追い出しの表示になるが、
手を離せば整う。

## 印刷・PDF

`Ctrl+P` か「印刷」ボタン。PDF は印刷ダイアログの「PDF として保存」で作る。

- 用紙は A4 横。1 行の字数から文字の大きさが決め直されるので、画面の
  文字サイズは印刷に影響しない
- マス目は刷られる。品詞マーカーと検索の強調は刷られない

| キー | すること |
|---|---|
| `Ctrl+O` / `Ctrl+S` / `Ctrl+Shift+S` | 開く / 保存 / 名前を付けて保存 |
| `Ctrl+Z` / `Ctrl+Y` | 元に戻す / やり直す |
| `Ctrl+F` / `Ctrl+H` | 検索 / 置換 |
| `F3` / `Shift+F3` | 次を検索 / 前を検索 |
| `Ctrl+R` | ルビを振る・直す |
| `Ctrl+B` | 傍点を付ける・外す |
| `Ctrl+Q` | 類義語を引く |
| `Ctrl+E` | 記法とプレビューの切り替え |
| `Ctrl+G` | 目次 |
| `Ctrl+P` | 印刷（PDF） |
| `PageUp` / `PageDown` | ページ送り |
| `Ctrl+Home` / `Ctrl+End` | 先頭へ / 末尾へ |
| `Esc` | 小窓・ヘルプ・検索バー・強調を閉じる |
